# 频道下载任务

## 创建

打开“下载任务”，点击“新建频道任务”，选择 Telegram 账号并搜索频道。搜索包含主列表和归档；也可每行粘贴一个当前账号可访问的频道或消息链接。每次最多建立 50 个任务，同一账号、同一频道复用已有任务。

默认勾选“下载全部历史，并持续下载新增文件”。关闭后从建立任务时开始监听新增文件。任务在创建时记录消息边界，历史扫描与新增补漏各自保存进度。

## 筛选

- 内容类别适合按实际用途筛选，例如“视频”同时覆盖普通视频消息和以文档发送的 MP4/MKV。
- 高级设置中的 Telegram 消息类型严格按发送方式筛选。内容类别与消息类型、关键词、日期、体积、扩展名及表达式需要同时满足。
- 关键词按文件名或说明文字匹配，不区分大小写。历史、新增和补漏采用同一条规则。
- 允许扩展名为空表示不限制；排除扩展名优先于允许扩展名。日期按浏览器当前时区转换，结束日期包含当天。
- 语音、圆形视频、GIF/动画及贴纸可单独选择。已有旧规则的空类型保持原四类范围，新任务的空类型表示全部已支持类型。

开始前可预览第一个所选频道最近消息的匹配样本。抽样结果不代表完整历史总量，历史扫描结束前任务仅显示已发现数量。

保存目录留空沿用当前下载位置；填写后复用现有的下载后按频道整理能力。目录使用运行服务所在系统的绝对路径。复杂目录策略、历史整理及整理失败处理仍可在“本地整理”中配置。

## 操作与状态

- 暂停派发：停止领取新文件，已经开始的文件允许继续完成。
- 继续：恢复派发，并检查暂停期间的新消息。
- 编辑规则：按新条件补扫历史，已完成文件继续复用。
- 重试失败：将失败及等待重试的文件重新放回队列，重置尝试次数。
- 补扫历史：重新核对历史；不会仅因重复扫描就重复建立同一文件任务。
- 导出清单：下载 JSON 文件，包含频道、消息 ID、发送时间、说明、文件路径及状态。

“历史已扫描”表示扫描已结束，可能仍有待下载文件；“历史已完成，持续监听中”表示当前文件任务已经处理完，任务仍继续接收新增文件。文件手动暂停、不可访问、限流、账号离线、下载时段及空间不足分别显示状态或原因。

## 升级

升级前备份数据库。1.4.0 为旧的自动下载规则建立持久任务与检查点，会重新核对历史元数据并复用已下载媒体。原有文件和整理规则继续保留；降级时使用升级前的数据库备份。
